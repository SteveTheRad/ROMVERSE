# ROMVERSE UI / UX

## Visual identity

ROMVERSE uses a dark/black interface with purple, blue, and cyan cosmic/neon accents, rounded glass-like panels, and clear green health/readiness indicators where appropriate.

Brand hierarchy:

**ROMVERSE — Created by SteveTheRad — A RadForge Labs Project.**

The full circular ROMVERSE Brand Badge is intended for larger brand surfaces such as website, installers/setup, About/credits, marketing, promotional material, trailers, and end cards. Small application icons should remain visually simple.

## Startup

Normal PC application launch must prioritize responsiveness. The previously planned blocking cinematic splash/sonic startup sequence is retired for normal app startup. Do not add decorative launch delay solely to show branding.

Approved cinematic and sonic assets may still be used in non-blocking or promotional contexts.

## Interaction principles

- Show real progress, not simulated progress.
- Explain current stage, warnings, dependencies, recovery options, and required user choices.
- Make confidence and uncertainty visible.
- Keep beginner language accessible while allowing deeper technical inspection.
- Prefer progressive disclosure over clutter.
- Preserve user context during long operations.
- Keep safety-critical choices explicit and understandable.
- Do not hide destructive consequences behind generic confirmation dialogs.

## Desktop direction

ROM Studio is the primary firmware workspace. Nexus, Pathfinder, Foresight, Guardian, Insight, Device DNA, and supporting workflow state should surface coherently rather than as disconnected tools.

## Companion direction

Primary mobile information architecture:

Home → Device → Nexus → Guardian → Tools → Community/Account

The Companion should share the PC application's cosmic/glass identity while being refined for touch, small screens, and accessibility.

Key mobile experiences:

- Pulse for real telemetry and before/after verification.
- Vitalis for health and diagnostics.
- Lifeline for recovery/rescue guidance and PC handoff.
- Live Console for real PC execution data, route, warnings, graphical events, gauges/graphs, technical output, and raw terminal details.
- A bottom-left Home control remains part of the current mobile direction.

## External/community surfaces

About ROMVERSE should include a professional Connect with ROMVERSE section including the official Facebook Page link. Community may surface the same official link where appropriate once that area exists.

## UX documentation rule

Material changes to navigation, visual hierarchy, terminology, launch behavior, safety prompts, or interaction patterns must be documented here alongside the implementation change.
